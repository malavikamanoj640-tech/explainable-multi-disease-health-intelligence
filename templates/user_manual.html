Getting Started

Create an account and access the system.

The Multi-Disease Prediction System allows registered users to securely access disease prediction, medical-report processing, prediction history and personalized risk-reduction features.

1

Create an Account

Open the registration page and provide the required user information. Create your account before using the prediction services.

2

3

Access the Dashboard

After successful login, use the dashboard to access disease prediction, reports, history and account-related features.

Making a Disease Prediction

Enter health information and generate a prediction.

Select the required disease prediction module and provide the health parameters requested by the system. The model processes the submitted information and generates an estimated prediction.

1

Select the Disease

Choose the disease prediction module available in the system.

2

Enter Health Parameters

Enter the requested medical and demographic parameters using the appropriate units and values.

3

Validate the Information

Check the entered values carefully before submitting the prediction.

4

Generate Prediction

Click the prediction button to submit the information for machine-learning analysis.

Tip

Always verify the entered health parameters before generating a prediction. Incorrect or incomplete information can affect the result.

Understanding Prediction Results

Learn how to interpret the generated result.

After a prediction is generated, the system presents several analytical elements to help the user understand the model's output.

Prediction

Displays the estimated disease outcome generated by the selected machine-learning model.

Confidence

Indicates the model's estimated confidence associated with the prediction.

Risk Factors

Highlights relevant input factors that may contribute to the estimated risk.

Risk Reduction

Provides personalized risk-reduction suggestions based on the available information.

Medical Report Upload

Use an existing medical PDF to simplify data entry.

The medical-report feature allows supported PDF reports to be processed automatically. The system attempts to identify relevant health parameters from the uploaded document.

1

Upload the Report

Select and upload a supported medical report file.

2

Automatic Extraction

The system analyses the document and extracts health parameters that can be identified.

3

Review Extracted Information

Review the extracted values before continuing with the prediction.

4

Complete Missing Information

If some required parameters are not available in the report, enter the missing information manually.

Important

Automatically extracted values should always be reviewed before they are used for prediction.

Medical Disclaimer

Important information about the use of predictions.

Educational and Decision-Support Use

This system is developed for educational, research and decision-support purposes. Predictions generated by machine-learning models are estimates based on the information provided to the system. They should not be considered a confirmed medical diagnosis, medical advice or a substitute for professional healthcare consultation. Users should consult a qualified healthcare professional for diagnosis, treatment and other clinical decisions.
